# Terminal Agent 🤖

An AI-powered terminal assistant that works in ANY directory. Simply run it from any folder, and it will operate within that folder as a sandbox.

## Features
- 🚀 **Portable**: Run from any terminal in any folder
- 🔐 **Secure**: Automatically sandboxes to current directory
- 📁 **File Operations**: Read, write, delete, list files
- 🖥️ **Terminal Access**: Execute shell commands safely
- 🤖 **AI-Powered**: Natural language understanding
- ⚠️ **Safety First**: Cannot escape sandbox or run dangerous commands
